# BloodChain DApp

**BloodChain DApp** - Blockchain-Based Blood Donor Tracking System

## Project Description

BloodChain DApp is a decentralized blood donor tracking system built on the Stellar blockchain using the Soroban SDK. The platform is designed to improve transparency, accessibility, and reliability in blood donor management through blockchain technology.

The system enables hospitals, health organizations, and communities to securely register, manage, search, and track blood donors using immutable blockchain storage. Each donor record is uniquely identified and maintained within smart contract storage, ensuring data persistence, transparency, and tamper resistance.

In addition to donor management, BloodChain supports emergency blood requests, donor reward systems, and blood type matching to help address real-world blood shortage issues and improve healthcare response efficiency.

## Project Vision

Our vision is to modernize blood donation management through decentralized technology by:

- **Improving Blood Accessibility**: Helping hospitals and patients quickly find suitable blood donors

- **Encouraging Participation**: Rewarding active blood donors with blockchain-based incentives

We envision a future where finding blood donors becomes faster, safer, and more reliable through decentralized systems.

## Getting Started

Deploy the smart contract to Stellar Soroban Network and interact using the main functions below:

### Donor Functions

- `create_donor()`
  Register a new blood donor

- `get_donors()`
  Retrieve all donor records

- `update_status()`
  Update donor availability status

- `delete_donor()`
  Remove donor data

### Search Function

- `search_by_blood()`
  Search donors by blood type

### Reward Function

- `add_reward()`
  Add reward points to active donors

### Emergency Function

- `create_emergency_request()`
  Create emergency blood requests

- `get_emergency_requests()`
  Retrieve emergency blood requests
